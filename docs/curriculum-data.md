The current catalog was carried forward from the supplied prototype and reorganized for deterministic filtering. On July 21, 2026, its source provenance and representative Grade 6, Grade 8, Grade 11, Grade 12 Government, Grade 12 Economics, and grade-span analysis-skill structures were checked against California Department of Education Appendix C. The interface descriptions remain locally shortened summaries rather than official verbatim standard text. It must not be represented as school-approved until a qualified educator checks every code, summary, grade/subject mapping, and local curriculum requirement.

The content standards and curriculum framework are related but distinct artifacts. The state-adopted content standards are the basis; the 2016 framework provides implementation guidance and republishes the standards in Appendix C.

## Release requirements

Before a pilot release:

1. Confirm the supported grade and subject combinations.
2. Verify every standard code and locally shortened description against the complete official text.
3. Record the reviewer, review date, and authoritative source version.
4. Document any school-specific additions separately from state standards.
5. Add tests for approved grade/subject mappings.

## Data rules

- Interface code must not contain curriculum decisions.
- A standard must have a code, description, source framework, and review status.
- Unverified data must be labeled as pending educator verification.
- AI output must never create or silently alter an academic-standard code.
