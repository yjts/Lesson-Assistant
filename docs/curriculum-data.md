# Curriculum Data

## Current catalog

- **Framework:** California History-Social Science Content Standards
- **Jurisdiction:** California
- **Prototype catalog version:** `prototype-2026-07-20`
- **Authoritative source:** https://www.cde.ca.gov/be/st/ss/
- **Educator verified:** No
- **Last educator review:** Not yet recorded

The current catalog was carried forward from the supplied prototype and reorganized for deterministic filtering. It must not be represented as school-approved until a qualified educator checks the codes, descriptions, grade/subject mappings, and any local curriculum requirements against the authoritative source.

## Release requirements

Before a pilot release:

1. Confirm the supported grade and subject combinations.
2. Verify every standard code and description.
3. Record the reviewer, review date, and authoritative source version.
4. Document any school-specific additions separately from state standards.
5. Add tests for approved grade/subject mappings.

## Data rules

- Interface code must not contain curriculum decisions.
- A standard must have a code, description, source framework, and review status.
- Unverified data must be labeled as pending educator verification.
- AI output must never create or silently alter an academic-standard code.
